# Credit Risk Assessment System
A professional Machine Learning web application that predicts whether a loan applicant is **Low Risk** or **High Risk** based on financial details.
---

## 🚀 Features
- Loan default risk prediction
- Real-time prediction
- Probability score output
- Clean and responsive UI
- Trained ML model integration
- Fast and accurate results
---

## ⚙️ Installation
### 1️⃣ Clone Repository
```bash
git clone https://github.com/venkatesh-ai-ml/credit-risk-assessment-system.git
cd credit-risk-assessment-system
```

### 2️⃣ Create Virtual Environment
```bash
python -m venv venv
```

### 3️⃣ Activate Virtual Environment
**Windows**
```bash
venv\Scripts\activate
```

**Mac/Linux**
```bash
source venv/bin/activate
```

### 4️⃣ Install Dependencies
```bash
pip install -r requirements.txt
```

## ▶️ Run Project
```bash
python app.py
```

Open browser:
```bash
http://127.0.0.1:5000/
```
