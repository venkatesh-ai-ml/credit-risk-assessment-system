# Credit Risk Assessment and Loan Default Prediction System

A Flask-based Machine Learning web application that predicts whether a customer is low risk or high risk for loan default.

## Features
- Loan default prediction
- Beautiful HTML/CSS UI
- Real-time predictions
- XGBoost trained model

## Tech Stack
- Python
- Flask
- HTML
- CSS
- JavaScript
- Scikit-learn
- XGBoost

## Run Project

pip install -r requirements.txt
python app.py
